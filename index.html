SISPA HOSPITAL

Instala o actualiza el sistema en esta computadora. Tus registros no se borran.

Descargar SISPA HOSPITAL para Windows

Pesa unos 40 MB. Solo se hace una vez en cada computadora.

  1. Cierra SISPA HOSPITAL si está abierto.
  2. Descarga el archivo y déjalo en tu carpeta Descargas.
  3. Ábrelo. Si Windows lo detiene, elige Más información y luego Ejecutar de todas formas.
  4. Revisa la carpeta que te muestra y pulsa Sí.
  5. Espera alrededor de un minuto. SISPA HOSPITAL se abrirá solo y quedará un acceso directo en el escritorio.

Después de esto, las actualizaciones llegan solas: cuando salga la barra verde en SISPA HOSPITAL, pulsa Actualizar ahora.
